## 数据与适配器覆盖

- 初始 5 / 小于 3 / 团队共同 31 / 未量化 / 退出 4 的口径保持正确。
- 团队成果、未确认上界、未知数量与退出记录不混入非团队新增指标；未知群人数不按 0 计算。
- 真正的 0 可保存；负数、上界 0、无效日期、危险证据链接被拒绝。
- 未设截止日期的任务不判断为逾期，已完成/取消任务排除。
- 删除父记录解除关联，保留子记录；悬空关联和重复来源被拒绝。
- JSON 重复导入幂等，冲突默认保留本地；CSV 处理引号、换行、公式前缀。
- 本地刷新保留数据，旧版本提交不能覆盖新版本；存储损坏与空间不足不会自动清空已有数据。
- CloudBase 模拟契约覆盖认证前置、owner 查询、首次初始化、条件版本更新与失败反馈；不代表真实云权限验证。
- 企业微信离线模拟覆盖完整分页、候选来源去重、缺失成员数、只保存文本摘录和循环游标停止。

## 复现

```powershell
npm ci
npm test
$env:VITE_DATA_MODE='github'
$env:VITE_GITHUB_REPOSITORY='owner/repository'
$env:VITE_GITHUB_BRANCH='main'
$env:VITE_GITHUB_DATA_PATH='data/workspace.json'
$env:VITE_GITHUB_EDITOR_LOGIN='owner'
$env:VITE_BASE_PATH='./'
npm run build
```

界面流程脚本针对全新测试工作区，正式用户数据请勿用于该脚本。企业微信凭据仅保留在 CLI 管理的本机位置，测试和交付包中不包含它们。
